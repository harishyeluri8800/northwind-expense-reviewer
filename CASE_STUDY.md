# Case Study - Northwind Logistics AI Expense Reviewer

## Overview
This branch contains the complete Case Study implementation.

## Features
- FastAPI backend with 8 REST endpoints
- React frontend with drag-drop receipt upload
- Claude AI integration for policy evaluation
- SQLite database with full audit trail
- 13 company expense policies
- Human override with audit log
- Policy Q&A with cited answers

## How to Run
```bash
# Backend
python main.py

# Frontend
cd frontend
npm install
npm start
```
